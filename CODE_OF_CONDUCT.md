# Code of Conduct

README Arcade is intended to be a practical and welcoming open-source project.

## Expected Behavior

- Be respectful and specific when reviewing work.
- Critique code and ideas, not people.
- Provide enough context for others to reproduce a problem.
- Respect privacy and do not publish credentials or personal information.
- Accept maintainers' decisions about project scope.

## Unacceptable Behavior

Harassment, discrimination, threats, deliberate disruption, spam, and
publication of another person's private information are not acceptable in
issues, pull requests, discussions, commits, or other project spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict
participation when necessary. Serious abuse on GitHub should also be reported
through GitHub's built-in abuse reporting tools.

Security reports are governed by [SECURITY.md](SECURITY.md), not this file.
