# Support

## Setup and Usage

Start with the [Quick Start](README.md#quick-start) and the configurations in
`examples/`.

For a reproducible problem, open a bug report and include:

- the selected mode and speed;
- the smallest configuration that reproduces the problem;
- the Python version or GitHub Actions run URL;
- the relevant error output;
- a screenshot for visual rendering problems.

Use a feature request for new modes or behavior changes. General Python,
GitHub Actions, and profile README questions are best handled in their
respective community support channels.

Security vulnerabilities must not be posted publicly. Follow
[SECURITY.md](SECURITY.md).
